# FORMA / THRESHOLD

A static gallery website for the 31-piece FORMA architectural woodworks collection.

## Publish with GitHub Pages

1. Create a new GitHub repository. Keep it public if you are using GitHub Free.
2. Upload all files and folders in this directory, including `index.html`, the `piece-*.html` pages, `assets`, and `images`.
3. Open the repository on GitHub and go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then click **Save**.
6. After GitHub finishes deploying, open the URL shown in the Pages settings.

The live address will normally be:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

If the repository is named `YOUR-USERNAME.github.io`, the address becomes:

`https://YOUR-USERNAME.github.io/`

The site uses relative links, so all gallery pages and images work from either URL format.
